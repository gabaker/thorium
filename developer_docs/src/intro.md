# Thorium Developer Docs

---

This book holds design docs and plans for Thorium internals. It is aimed at Thorium
developers, not users or operators:

- User and admin documentation lives in the user docs book at `api/docs` (served from the
  running API and on GitHub Pages).
- API-level reference documentation is generated by rustdoc (`cargo doc`) in CI.
- This book documents *why* and *how* Thorium's internals are changing: design decisions,
  cross-component plans, and migration strategies that don't belong in user-facing docs.

## Building This Book

This book uses [mdBook](https://rust-lang.github.io/mdBook/) with the
[mdbook-mermaid](https://github.com/badboy/mdbook-mermaid) preprocessor for diagrams. It
is not currently built in CI; build it locally:

```bash
# one-time setup
cargo install mdbook mdbook-mermaid
# serve the book locally with live reload
mdbook serve developer_docs
```

If you add a new page that uses mermaid diagrams, no extra setup is needed — the
preprocessor is already wired into `book.toml` and the mermaid JS assets are checked in.
If the assets ever need to be regenerated (e.g. to pick up a newer mermaid version), run
`mdbook-mermaid install developer_docs`.

# thorpal-harness

Runs a workflow run's entry agent with ThorPal. It supports `AnthropicMessages` models on an
`Anthropic` endpoint with an `ApiKey` credential, `ThoriumMcp` and `Container` tools bound to the
`ThoriumApi` mechanism, the entry agent only (no sub-agents), and one input sample per run. See
the Developer Guide's "Registering the ThorPal Harness" page.

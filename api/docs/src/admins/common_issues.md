# Common Issues

While Thorium is intended to be as easy and low maintenance as possible it
is a scalable distributed system. As such at times issues will arise. This
section aims to explain how to debug and resolve common issues.

- [Jobs Stuck At Created](./common_issues/jobs_stuck_at_created.md)

Problems deploying, upgrading, or running the Thorium operator and its `ThoriumCluster` are
covered in [Troubleshooting Deployments](./deploy/troubleshooting.md).

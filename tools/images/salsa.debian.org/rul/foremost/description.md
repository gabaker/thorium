# Foremost

Foremost is a file recovery and carving tool that recovers files based on their headers and footers. It can work on image files (such as those generated by dd, Safeback, or Encase) or directly on a drive.

## Overview

Foremost scans raw data for the byte signatures that mark the start (header) and, optionally, end (footer) of files, then extracts the matching regions as recovered files. The file types it searches for are defined entirely by a configuration file that specifies each type's extension, case sensitivity, maximum size, header, and footer; sample entries shipped with the tool cover formats such as GIF and JPEG. In this deployment the tool runs in verbose mode (`foremost -V`) over the input and emits carved files as child artifacts along with its audit report.

## Supported File Types

- Disk and forensic image files (e.g. dd, Safeback, Encase) or raw drive data
- Any binary input that may contain embedded files matching the configured header/footer signatures

## Usage

Run Foremost when you have a disk image, raw dump, or other binary blob that may contain embedded or deleted files you want to extract. It is well suited to digital-forensics workflows where files must be recovered or carved out of unstructured data using known file signatures rather than filesystem metadata. The carved outputs are returned as children for further analysis, and an audit report of what was recovered is captured as the result.
